# SubLoop

Optimiza la rotación de tus suscripciones de streaming: mira un servicio por mes,
ahorra en los demás y vuelve meses después con contenido acumulado para disfrutar.

## Qué hace

- Registra tus suscripciones (precio, fecha de cobro y prioridad).
- Define tu presupuesto mensual.
- Guarda tu watchlist por servicio.
- Calcula un plan de rotación mensual para maximizar lo que ves gastando menos.
- Te muestra cuánto ahorras frente a mantener todo activo.

## Stack

React Native / Expo · Supabase · TypeScript.
